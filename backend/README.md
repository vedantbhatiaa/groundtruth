# Backend

FastAPI app serving the graph queries, RAG search, and chat orchestration.

## Run locally

```bash
cd backend
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp ../.env.example ../.env     # then fill in GROQ_API_KEY and Neo4j password
uvicorn app.main:app --reload --port 8000
```

API docs (auto-generated by FastAPI) are then at http://localhost:8000/docs

## Run tests

```bash
pytest tests/
```

## Folder guide

- `app/config.py` — the only place that reads environment variables
- `app/db/` — one client per storage backend (Neo4j, ChromaDB, SQLite)
- `app/models/` — Pydantic request/response schemas
- `app/routers/` — HTTP endpoints, grouped by resource
- `app/services/` — the actual logic: graph queries, RAG, LLM calls,
  the chat orchestrator, and the three external data sources
